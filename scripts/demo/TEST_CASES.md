## 用例 2 —— Excel 全能力:清洗 → 建模 → 修错(用两个 .xlsx)

**覆盖**:Excel 分析(表格模式,SQL 弱化)、脏数据清洗、加分析 sheet、可计算金融建模、公式报错修复。

**A. 清洗 + 加 sheet**(拖 `~/Downloads/daclaw_demo.xlsx`):
```
月度目标表有脏数据(缺失值、N/A、"85%"文本百分比),清洗它;再新增一个"达成分析"sheet,把实际销售(从销售明细按月汇总)和目标对比、算达成率,保留原有 sheet,给我可下载的工作簿。
```

**B. 可计算 DCF 建模**(不用上传,直接问):
```
用真 Excel 公式建一个 5 年 DCF 模型:营收 1000 起、年增 15%、FCF 率 30%、WACC 9%、永续增长 2.5%,算企业价值;再加一张 WACC×永续增长 的双变量敏感性表,每格必须公式联动、禁止写死数字。
```

**C. 公式报错修复**(拖 `~/Downloads/broken_finance.xlsx`):
```
审计这个财务表,列出所有公式错误(#DIV/0!、硬编码、逻辑错),然后全部修好、重算验证错误消失,给我修正版。
```

**看点**:① 右侧 Excel **预览表格 + 下载完整版**;② DCF 敏感表是真公式(离线重算验证过);③ 修复走"审计→改→验证"闭环。

## 用例 3 —— 数据工程:自然语言自动搭 dbt 管线(`/etl`,先在数据智能体拖过 `daclaw_demo.duckdb`)

**覆盖**:auto-DBT 全流程 —— 分层建模、ref() 血缘 DAG 可视化、拓扑物化、节点检查、导出 dbt project。

切到 **数据工程** 页面,输入:
```
构建电商分析 dbt 管线:staging 清洗 customers/orders/order_items/products 四张原始表;intermediate 建订单行级营收、客户维度、月度品类聚合;marts 建三张业务表——客户 RFM 分层、月度品类营收趋势(含环比)、城市业绩排名。用 ref() 串起来。
```

**看点**:① 四列分层 DAG(raw→staging→intermediate→marts)彩色节点 + 血缘连线;② 每个节点显示行数✓;③ 点节点看该模型的高亮 SQL + 数据预览;④ 右侧显示"已导出 dbt project · N 个文件"。
