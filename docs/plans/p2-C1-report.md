- 添加 `MemoryService`、`MemoryRevision`，正文写入已有 ArtifactStore。支持新建、历史读取、修订、确认、拒绝、遗忘和候选提议。有效期区分未传、null、新时间三种状态；有期限的偏好自动维护 `temporary` 标签。提议按 NFKC、casefold、标点/分隔字符/空白过滤后比较 kind、摘要、正文，检查当前记忆及被拒绝候选；满 10 条候选时记录 warning 并返回 None。

- 计划 §2.4 的“候选永远不能替换任何记忆”与 C1“revise 保持状态”的字面范围不同。本次遵循卡片：模型提议 `propose` 只新增；用户通过可信 API 修订候选可以生成新的 CANDIDATE 版本，只有可信确认操作生成 CONFIRMED 版本。
- 卡片没有规定用户修订/确认后的 `source_ref`。新版本记录为 `user:<actor_id>`，旧来源通过 `supersedes_id` 留存。这也避免 task 来源历史唯一索引阻止用户确认/修订；原 task 重试仍返回原记录，测试已覆盖。
