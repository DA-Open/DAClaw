# DAClaw Internal Docs

## 中文速读

如果你是为了看懂仓库，建议按这个顺序读：

1. `repository-inventory.md`：先知道每个目录有什么用，哪些可以暂时不用管。
2. `current-architecture-map.md`：再理解当前 Hermes/OpenClaw 继承架构怎么跑起来。
3. `repository-cleanup-roadmap.md`：最后看怎么整理、怎么稳定 Web、怎么走向桌面软件。
